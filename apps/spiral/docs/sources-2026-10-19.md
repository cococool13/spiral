# Wallpaper source review, 2026-10-19

Checked 2026-10-19. This note records the license for four background sources from that day's review. It does not add a source to the app.

Spiral Wallpaper ships one source: Wallhaven. Search, thumbnail, and apply go through `src/sources/index.ts`. The Rust client accepts only `wallhaven.cc` hosts (`src-tauri/src/net.rs`). There is no curated pack of bundled images. `CONTEXT.md` says adding a source is a product decision. None of the licenses below clearly permits bundling these files in the app, or linking them so the app downloads and sets them as the desktop background. No image was added. No source code was changed.

## Signup note for Backgrounds Supply

The freebies page says you sign in with email to download the free pack. The FAQ says the free pack downloads with no email. Both pages say the free pack is personal use only. The signup difference does not change the license result.

## Decision

Leave the app code unchanged. No license clearly permits bundling or linking. The app has no curated-pack list to extend. Wallhaven remains the only source.
